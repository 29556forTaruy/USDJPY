# USDJPY

日銀短観と日米金利差を用いたUSD/JPYモデルの復元・検証・前向き評価プロジェクトです。

2026-09-20時点で、過度適合を抑えた精度改善V2に加え、監査版Fear & Greed、移動平均、前年OHLCの年足ピボットを統合した日次ハイブリッドモデルを実装しました。履歴結果だけでは本番モデルへ昇格させず、どちらもシャドー運用しています。

## 現在の成果

- 理論値乖離の収束モデル
- 変化率リッジモデル
- 3か月政策期待モデルと2年金利差診断
- 動的係数モデル
- ランダムウォーク比率35%以上の縮小アンサンブル
- 初回公表時点を考慮した履歴検証
- 追記専用台帳による前向き検証
- 毎日09:40 JSTの自動実行
- 監査版Fear & Greed、20/50/125/200日移動平均、前年OHLC年足ピボット
- 1・5・20日予測と乖離率によるコスト控除後ポジション構築
- 合計70件の自動テスト（基礎・V2 44件、ハイブリッド26件）

## 現在の判定

変化率モデルは対応するランダムウォークに対してRMSEを4.49%、MAEを7.09%改善しました。RW下限アンサンブルはRMSEを3.75%、MAEを4.42%改善しました。

一方、事前に固定した昇格条件であるRMSE 5%以上の改善、期間安定性、多重検定補正後の有意性を同時に満たした候補はありません。したがって、現時点の判定は「本番昇格なし・シャドー継続」です。

日次ハイブリッドモデルも、1・5・20日RMSE改善率がそれぞれ-0.35%、-1.91%、-3.11%、コスト控除後の累積損益が-2.19%、Sharpeが-0.45でした。単純な変化なし予測、MAクロス、ボラ調整済み常時ロングを上回らないため、本番昇格は明確に見送っています。2026-09-19終値時点の予測は1日156.905円、5日156.997円、20日157.995円ですが、コスト控除後シグナルが新規閾値未満のため目標ポジションは0です。
